# 탈환 작전실 요약과 가린 서버 확인 기록

화면의 **탈환 작전실**은 `GET /api/operations` 응답만 읽습니다. 기존 로그인 검증 도우미와 11단계의 현재 로그인·기기 증명 검사를 통과해야 하며, 브라우저 role·userId·deviceRegistered를 권한으로 사용하지 않습니다. 무로그인은 401 JSON, 미승인/회수 기기는 403 JSON, DB/응답 이상은 503 JSON입니다. 기능·사용자 선택 쿼리와 쓰기 요청은 허용하지 않습니다.

## 확인한 것과 미실행의 구분

| 표시 | 실제 출처와 의미 |
| --- | --- |
| 판정기 규칙 수·이름 | 서버가 import한 `RULE_IDS`의 현재 구성. 규칙이 실제 접속에서 실행됐다는 뜻은 아님 |
| 탐지 사건 | 현재 연결된 실제 사건 기록이 없어 **미실행 / 기록 미연결**. 0건으로 추정하지 않음 |
| 내 기기 회수 상태 | 검증된 로그인 소유자의 `vault_devices` DB 현재 상태 중 revoked 개수 / 전체 개수. 실제 엔진의 회수 집행·시각을 확인한 결과는 아님 |
| 복구 실행 버전 | 현재 연결된 복구 실행 기록이 없어 **미실행 / 기록 미연결**, API 버전 값은 null. 설정 step·사본 형식·정책 형식 버전을 복구 완료 버전으로 바꾸지 않음 |

API는 `schema: vault.operations.v1`, `observedAt`, `records`만 반환합니다. `observedAt`은 서버가 조회를 마친 시각이며 실제 판정·탐지·회수·복구 발생 시각이 아닙니다. 기록 종류는 rules, decisions, detection, revocation_execution, recovery, device뿐입니다. 미연결 네 종류는 status=unrun이며 가상 연습 결과나 사용자 과거 보고를 자동으로 실제 기록에 넣지 않습니다.

기기 기록은 id·owner_id·자격 증명·공개키·세션을 화면에 보내지 않고, 현재 DB 상태와 표시용 가명 `d-` + 12자리 지문만 내보냅니다. 표시용 가명은 계정 범위를 포함한 단방향 변환이며 제공 엔진의 기기 ID나 복구 대상 ID가 아닙니다. 작전실 요약은 메모·사본·감사 원문 테이블을 조회하지 않으며 메모 제목/본문·토큰·실명·키를 저장하거나 로그·응답에 넣지 않습니다. 기존 DB와 감사 이력을 수정하지 않습니다.

**가린 서버 확인 기록**을 펼치면 동일 API 응답에서 나온 항목을 볼 수 있습니다. 규칙 수는 ruleIds 길이, 기기 상태 수는 device 항목의 상태별 개수로 계산하고 별도 하드코딩한 수치를 섞지 않습니다. 기록 개수도 records 길이와 같아야 합니다. 이 목록은 현재 상태 스냅샷이며 영구 감사 이력이나 실제 사건 타임라인을 새로 만든 것이 아닙니다. 여러 DB 조회를 단일 운영 감사 트랜잭션으로 보장한다고 주장하지 않습니다.

조회 대상은 본인 기기로 제한합니다. 응답에 타인 소유자·중복 기기·잘못된 상태가 섞이거나 256개를 넘으면 불완전한 개수 대신 실패합니다. 현재 승인 기기가 조회 중 사라지거나 회수되면 거부합니다. 서버 기록 조회가 실패하면 화면은 **미확인**을 표시하며 0이나 성공으로 대체하지 않습니다. 로그아웃·기기 승인 해제·늦게 도착한 응답에서는 이전 계정의 요약과 가린 기록을 지웁니다.

## 직접 대조하는 순서

1. 11단계 SQL·실제 승인 준비가 된 배포에서 **로그인 → 이 기기 확인 / 결과 조회**로 서버 승인을 확인합니다. 승인 전에는 작전실 API를 요청하지 않고 화면도 숨겨져야 합니다.
2. **탈환 작전실 → 서버 기록 새로고침**을 누르고 개발자 도구 **Network → operations → Response**를 엽니다. 쿠키·Authorization·다른 요청의 본문은 복사하거나 공유하지 않습니다.
3. 화면 규칙 수·이름을 rules.ruleIds와, 회수 수치를 device 항목 중 revoked 수 및 device 전체 수와 대조합니다. 펼친 가린 기록 개수는 records 배열 길이와 같아야 합니다. 새로고침 전후 다른 응답을 섞지 않습니다.
4. 탐지·실제 판정·엔진 회수 집행·복구 버전의 unrun 표시를 확인합니다. 기록 미연결 상태를 탐지 0건·회수 성공·버전 복구 완료로 읽지 않습니다.
5. **로그아웃**하면 작전실이 숨겨지고 이전 수치·가린 기록이 사라져야 합니다. 무로그인 직접 GET은 401 JSON이고, 로그인만 하고 기기 승인을 확인하지 않은 직접 GET은 403 JSON이어야 합니다. 승인된 기기의 기존 자기 메모 CRUD와 타인 자료 거부는 유지돼야 합니다.

재실행: `node --test test/operations.test.mjs test/operations-ui.test.mjs test/auth-ui.test.mjs`.

관련 시험 25개와 전체 로컬 시험 135개·로컬 빌드가 통과했습니다. 실제 SDK/서버 함수를 모의 DB와 연결해 마스킹·수치 대조·소유자 범위·무로그인/미승인 거부·기록 미연결·늦은 응답 삭제를 검사했습니다. 실제 학습 DB의 승인 기기 세션으로 이 API를 호출하거나 새 배포·화면을 확인한 것은 아닙니다. 실제 SQL 적용·실기기 승인·작전실 실측은 미실행입니다.

## 단계별 실제 요청 결과 표

1~11단계 정상·금지 요청의 실측은 [요청 실측표 절차](REQUEST_VERIFICATION.md)의 한 표에 별도로 기록합니다. 41행은 기존 요구를 기준으로 만든 자체 점검 목록이며 현재 모두 미실행입니다. 작전실의 현재 상태 records·observedAt은 각 시험의 실제 응답·요청 추적 ID·확인 시각을 대신하지 않습니다. 이 표를 자동으로 읽어 완료 수를 올리거나 사건 이력으로 저장하는 기능은 추가하지 않았습니다.
